# IndexedDB Tutorial in Bangla - ব্রাউজার স্টোরেজ ও JavaScript Database - Initial Source Code

IndexedDB Complete Engineering Crash Course-এ আপনাকে স্বাগতম! আপনার ওয়েব অ্যাপ্লিকেশনের structured data persistence এর জন্য Local Storage বা Cookie কি আর যথেষ্ট? এই ভিডিওতে আমরা থিওরি বাদ দিয়ে সরাসরি আর্কিটেকচারাল ইমপ্লিমেন্টেশনে যাব।

আমরা দেখব কেন Local Storage রিয়েল-ওয়ার্ল্ড অ্যাপ্লিকেশনে main thread ব্লক করে দেয় এবং কীভাবে ব্রাউজারের নেটিভ asynchronous ও transaction-based ডেটাবেস "IndexedDB" এই লিমিটেশনগুলো দূর করে। PWA (Progressive Web Apps) বা offline-first অ্যাপ্লিকেশন বানানোর জন্য এই কোর কনসেপ্টগুলো জানা প্রত্যেক ডেভেলপারের জন্য জরুরি।
